# A12 实测刷具覆盖几何

正式覆盖重建使用 `scripts/formal_cleaning_geometry.py`，不把整车声明的
`1.32 m` 有效作业幅宽当作每个侧刷的直径。权威输入是
`config/high_fidelity_vehicle/formal_motion_cleaning_profile.yaml`、清扫机构
Xacro 和 `GroundDirtCleaningSystem` 的参数；计算结果保留输入文件哈希。
这些物理参数不因覆盖成绩而调整。

| 刷具 | 底盘坐标中的中心 xy（m） | 平面扫掠代理 |
|---|---|---|
| 左侧刷 | (0.385, 0.545) | 半径 0.150 m 圆盘 |
| 右侧刷 | (0.385, -0.545) | 半径 0.150 m 圆盘 |
| 中央滚刷 | (0.155, 0) | 长 0.200 m、宽 0.620 m 矩形 |

滚刷矩形沿用现有仿真的刷毛扫掠代理，不是刚性圆柱与地面的真实接触面积。
单姿态三个足迹不相交，其解析并集为 `0.2653716694 m²`。侧刷内缘与
滚刷边缘各有 `0.085 m` 横向间隙；`1.390 m` 外包络也不等于连续清扫宽度。

## 原始观测与接口

回放读取现有评测隔离桥的
`/evaluation/single_episode/ground_dirt/status_json`，保持原始状态字段。
该话题仅供评测，不能供产品控制、感知或规划订阅。控制命令非零不能代替
真实关节转速、升降位置和接地间隙。

`sample_from_ground_dirt_status(status, stamp_s, geometry=None)` 将同一条状态
中的左右侧刷世界中心反解平面航向与底盘位置，并核对中央滚刷中心。
这是平面刚体重建；不符合该几何关系的倾斜或未初始化观测会被拒绝，不能
通过放宽容差冒充已验证的非平面扫掠。地图坐标任务必须使用冻结任务几何中的
`source_fixed_start_pose` 做世界到地图的起点反变换；缺少坐标系声明不能默认为零。
`empirical_cleaning_metrics(outer_polygon, samples, geometry=None, ...)`
供独立直播指标和 MCAP 回放共同使用，目标区外和禁区内的格点不计入覆盖。
回放时间使用 MCAP 接收时间；原始状态没有仿真源时间戳，因此不能宣称已验证
源时间同步精度。直播与回放必须保留各自的时间来源和原始数据。

每个刷具独立满足系统启用、地污布局就绪、升降位置至少 `0.095 m`、实测
转速绝对值至少 `2 rad/s`、离地间隙在 `[-0.004, 0.015] m` 内才计覆盖。
缺字段或非有限数值不能被当作已接地。停刷断开该刷具的扫掠连续性；时间
断层或异常位移不跨越插值。平移和最短角旋转共同决定空间采样密度。
重复经过、左右刷或滚刷重叠均只计一次覆盖并集。

## 验证与边界

专项测试：

```powershell
py -3 -m pytest scripts/test_formal_cleaning_geometry.py scripts/test_formal_product_mcap_replay.py -q
```

测试核对解析圆盘、胶囊扫掠、矩形及并集面积、禁区裁剪、独立启停、离地、
缺失状态、时间断层、纯旋转和跨越正负 π 的航向。离线数值通过不等于真实
覆盖率达标，也不等于土污去除、接触力或比赛效率已经通过。

正式运行仍需在同一新 session 中录制原始状态，验证桥接、时间口径、采样
连续性和直播/实际 MCAP 播放复算的一致性。旧的 command-only 录制不能补作
当前接地证据。运行资源由正式仿真任务独占，本几何修复不启动竞争仿真。
