# 正式整车实物建造就绪度

## 结论

当前交付是**高静态完整度的名义数字样机**，状态固定为
`NOT_READY_FOR_FABRICATION_OR_REAL_WORLD_ACCEPTANCE`。它不是可直接下料、采购、装配或宣称
实车验收通过的制造包。

当前冻结展开产物记录为 **196 links、195 joints、160.007583 kg**，其 SHA-256 为
`2b399eaba8de34fd55ca663a3b6b49437070c72969f5e22faf2a64a12ba27db8`。快照的 source inventory
摘要为 `3e3d75364b2e8af6b688de854e41203b5edd27244b529a34f36840ded03e8bd3`，output inventory 摘要为
`2373c4f4aac55bf4690c1ce0d163c0cb6fb5be45cef911873473c44ab020c0f3`；只读校验会在任一源或输出
漂移时失效。这证明的是当前**数字快照**而非可制造或实物状态，不能据此关闭任何 Gazebo、赛题或实车门。

与该快照相同 URDF/布局哈希绑定的静态 FOV 报告为
`4cb1a8bdd37828eefb107248d3ed98d2dfb2c1d6ded009986aeaa6e5010c0014`，静态惯量/扫掠报告为
`b9d287bc6b625e2295b02d6083febc8dfcdadf8d4ba9b9b438d2fd981ea7a6c6`。它们可作为当前数字样机的
静态分析输入，但明确不替代运动中可见性、实物安装标定、实测重心/惯量、结构试验或动态稳定性验收。

## 质量与吞吐量边界

赛题映射本身没有规定整车总质量上限；本项目的质量门是底盘工程约束，而不是把它表述为赛题
总质量限制。Clearpath A300 公开的平地额定 payload 为 **101.5 kg**，项目按 `0.9` 设计系数
采用 **91.35 kg** 设计载荷。最后展开产物含两个动态载荷状态 link、各 0.001 kg 的数值稳定
质量；装载时它们由真实干垃圾/污水质量严格 replace。两种必须同时保留的计算为：

```text
物理满载余量（扣除 2 g reserve）
  = 91.35 - ((160.007583 - 0.002) - 78.5 + 1.512 + 8.30)
  = 0.032417 kg

保守放行余量（不扣 reserve）
  = 91.35 - (160.007583 - 78.5 + 1.512 + 8.30)
  = 0.030417 kg
```

实物质量替换时的物理余量为 32.417 g；放行仍使用更保守的 30.417 g 门。任何线束、紧固件、
工装、传感器改型或实际液体质量偏差都必须重新称量、复核重心和结构安全。两者都不是实物载荷验收。
这不是干湿载荷重复计入：`DynamicPayloadSystem` 先从固定关节归并后的基线移除两个 1 g seed，
再仅写入“结构基线 + 当前干质量 + 当前污水质量”；实体保留的垃圾方块不得再发送到 aggregate
干载荷话题，`DryBinMonitorSystem` 只仪表化同一质量而不重新施加动力学。

### 展开 URDF 质量分项与制造余量

以下分项来自当前冻结展开 URDF 的每个有惯量 link；其合计严格为 **160.007583 kg**。这只是
可复算的数字审计基线，不能作为实物称重或制造/实车冻结源的替代。

| 子系统 | 质量（kg） | 最大贡献 |
|---|---:|---|
| A300 底盘、四驱、电池与编码器 | 78.500000 | `base_link` 35.5 kg、双电池各 7.35 kg |
| 六轴臂、2F-85、腕部 D435、控制箱与臂座 | 40.342576 | 控制箱 11.32 kg、上臂 8.058 kg、臂座 6.5 kg |
| 车身、服务门与安全外设 | 12.280004 | 下底盆 3.8 kg、前罩 3.4 kg、后壳 3.1 kg |
| 清扫与回收 | 11.125000 | 泵电机 1.35 kg、滚刷 1.22 kg、泵头 0.95 kg |
| 干湿箱、投放与排污 | 10.362001 | 箱架 0.9 kg、干箱本体/盖各 0.75 kg |
| 传感器塔与传感器 | 3.948001 | 塔体 1.45 kg、UTM 支架 0.42 kg |
| 供电与计算 | 3.450001 | S100 保护盒 1.72 kg、DC/DC 0.4 kg |
| **总和** | **160.007583** | 与展开产物的 `mass_kg` 严格复算一致 |

制造放行不采用 30.417 g 的现有保守余量。最低目标是 **5 kg**，建议目标是 **10 kg**；按不扣
reserve 的保守口径，分别需要已验证地减去至少 **4.969583 kg** 与 **9.969583 kg**。严禁直接
改小 URDF 质量、惯量或 reserve 来声称达到这些目标。任何 credit 必须来自项目自研件的物理改型、
称重、重新计算惯量/重心和重新冻结后的审查。

当前 5 kg 候选只包括下列保持功能的项目自研件，且统一是 `design_required_not_credited`：

1. 臂座/转接盘：优化承载路径，不改变 UR5e、2F-85 或工作包络；
2. 车身壳体与非安全外覆：不削减碰撞防护、急停、灯光和检修闭锁；
3. 干湿箱架与箱体结构：保留独立 40 L 干箱、8.3 kg 污水、挡板、盖锁和排污功能；
4. 传感器塔与支架：保持所有传感器、视场和标定基准；
5. 清扫头支架与护罩：保留泵、电机、刷辊、刮水、吸口和回收能力。

任一候选在实物改型、称重、惯量/CoG 复算、结构 FEA/屈曲/疲劳、振动、防水和功能验证完成前，
均不得抵扣任何预算；不得直接改小 URDF 质量、惯量或 reserve，也不得删除 A300、UR5e、2F-85、
传感器、40 L 干箱、8.3 kg 污水容量或清扫回收功能来宣称减重。

若完成这些可验证改型后仍不能保留 5 kg 余量，则应重新选型额定 payload 至少 **107.02 kg** 的
底盘；若目标是 10 kg，至少 **112.58 kg**。两个值都沿用 0.9 设计载荷系数。更高标称 payload
不替代满水、伸臂、制动、转弯和坡道下的稳定性验收；其中任一稳定性失败仍要求更换为更稳定的平台。

常规清扫的理论能力为 3564 m²/h，只比 3500 m²/h 门槛高 64 m²/h。该预算不能替代地面实际
清扫、能耗、行人避障、返航或连续运行测量。

[`formal-vehicle-electrical-thermal-release.md`](formal-vehicle-electrical-thermal-release.md)；其机器可读
声明可由 `scripts/validate_electrical_harness_thermal_readiness.py` 只读复算。
