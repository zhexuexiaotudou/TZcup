# 竞赛演示脚本

本脚本只用于展示已通过的独立软件能力，不宣称 AUTO-15 综合竞赛通过。

1. 展示 20,000 m² 大地图、20 个 zone 与定时任务配置。
2. 启动基础 Gazebo/RViz，确认车辆、传感器、TF 和安全节点。
3. 展示全覆盖、动态避障、边界保护与急停证据。
4. 展示 APP 的鉴权、幂等任务提交和中英文语音入口。
5. 演示受限 DSL 对合法任务的分解，以及对直接电机/关节命令的拒绝。
6. 展示离线抓取与满箱 fail-closed 证据，明确其不是实体机械臂运行。
7. 展示 AUTO-12 的离线动力学/栅格效率报告，并说明不是实车测量。
8. 打开 `reports/release/FINAL_COMPETITION_MATRIX.json`，现场说明 AUTO-08 与 J6 阻断，
   以及为什么综合 mission、视频和 MCAP 计数保持 0。

禁止展示或口播：

- 未执行的 30 次综合任务；
- 真实域准确率；
- J6 FPS、温度、功耗或稳定性；
- 两名真人盲审已完成；
- 完整竞赛证据已经通过。
