# 最少结果接入

仿真执行者继续独占运行资源。本工具只读取本地已结束产物；不启动仿真、不接入设备。

准备一个JSON数组，每项使用 `metrics/results.json` 中的id，填 `status`、`value`、`basis`、`note`、`run_id`、`source_commit`、`evidence`（原始文件绝对路径数组）。未改变项不必填。数值单位按id为mm、m²、m²/h、mm、s；basis必须属于脚本声明的证据类型，并写清它是measured_simulation、internal_frozen_regression、offline_replay、controlled_fixture_replay、synthetic_replay还是design_calculation。note写清统计口径和局部/全程范围，不得把内部回归、受控候选或设计计算写成现场测量。

示例是字段说明而非测量值，不提供虚假PASS样本。功能项value可为null。脚本检查文件存在与数字阈值，不代替人工检查JSON字段与日志事实、真值隔离或视频内容。

```powershell
py -3 tools/refresh.py --intake C:\绝对路径\结果接入.json
# 仅重建矩阵与PDF
py -3 tools/refresh.py
```

原始输入复制到包内新时间目录，旧矩阵留档。不要重跑根工作树build_minimum_package.py覆盖已接入结果。

执行者最少提供：

1. 一次完整任务summary.json（run_id、commit、六功能终态、五指标数值/单位/时钟/口径、失败原因）；相应任务日志与实际启动命令。
2. 已保存地图及面积统计、时间配对定位轨迹、污物清除并集/时间/有效宽度、行驶中急停速度序列。可合为metrics.json+采样CSV，勿仅给布尔PASS。
3. 能辨识建图/识别清扫/避障急停的截图，5–10分钟含操作说明的视频；填写video/视频索引.md。工具可按evidence复制文件，不生成视频。

预计拿到完整结果后10–20分钟完成接入、PDF重建、目视检查和压缩；不包括补测、录制视频、原始大文件传输。演示不合格不通过重命名或延长静帧补时长。
