# 专利与论文材料边界

## 1. 当前事实

基线仓库未找到项目已申请专利、授权专利、论文投稿或发表的证据。

因此：

- 官方“已申请专利或发表相关论文”加分项状态为 `NOT_ELIGIBLE_NO_FILING_OR_PUBLICATION`；
- 披露模板、检索清单和论文提纲不能替代受理回执或正式发表证明；
- 不填写虚构申请号、公开号、DOI、期刊或作者信息。

## 2. 候选方向

以下只作为待检索题目，不判断新颖性：

1. 工具自由且步骤受约束的毛刷/滤网更换机构；
2. 维护模式与远程任务互锁的安全控制；
3. 积水、落叶和容量变化联动的清扫策略；
4. 低速清扫车的边界安全与最小风险状态切换。

## 3. 披露前步骤

1. 记录最早构思时间、贡献者、单位职责和公开披露计划；
2. 做关键词、分类号和同族专利检索；
3. 保存检索日期、数据库、查询式、命中和结论；
4. 由单位知识产权负责人判断是否申请、论文是否影响新颖性；
5. 论文和专利公开顺序由授权流程决定。

## 4. 论文边界

`paper-outline.md` 只定义可复现研究问题，不声称已有实验结果。正式论文必须具备独立数据、对照、误差和限制。

## 5. 当前可写入报告

> 本材料包仅提供发明披露和论文提纲模板，仓库中没有已申请专利或已发表论文证据，因此不主张该项加分。
