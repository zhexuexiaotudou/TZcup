# 发明披露模板

## 1. 基本信息

- 工作标题：
- 建议贡献者：
- 所属单位：
- 最早构思时间：
- 已完成披露或公开：
- 计划公开时间：

## 2. 技术问题

说明现有清扫车在维护、安全、复杂工况或容量管理上的具体问题。禁止只写“更智能、更先进”。

## 3. 现有方案

列出已知产品、专利、论文或公开资料，并说明差异。每项保留来源和访问日期。

## 4. 发明要点

- 必要技术特征；
- 与现有方案的区别；
- 为什么这些区别不是常规替换；
- 可替代实现；
- 不能公开的技术秘密。

## 5. 证据与实验
