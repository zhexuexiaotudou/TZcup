# 可落地产业化方案评审摘要

## 1. 当前结论

现有 `codex/day1-value-package` 已包含园区/校园客户假设、H0-H4 部署阶梯、BOM 成本公式、试点里程碑、风险和 IP 清单。本包补充一个适合评委快速阅读的 gate 表。

当前状态：`REVIEW_READY_NOT_FIELD_VALIDATED`。

## 2. 推荐首个落地场景

优先级最高的是可围控高校/产业园或工厂园区：

- 固定路线和可冻结地图；
- 人车流可设置时段和边界；
- 车辆维护和充电位置明确；
- 能在低峰或夜间先做影子模式；
- 不把开放道路认证、量产 SLA 或跨城部署作为首轮承诺。

## 3. 商业化门槛

## 4. 成本输入规则

未取得正式报价前，BOM 单价保持 `UNSET`。成本模型可以写公式，但不能填猜测价格。

```text
C_unit_landed =
  sum(q_i * quote_i * fx_i)
  + assembly + calibration_QA + packaging + freight + duty_tax
```

任何 ROI 都必须同时给出低/基准/高三档、采购数量、汇率日期、电价、使用年限和残值来源。
