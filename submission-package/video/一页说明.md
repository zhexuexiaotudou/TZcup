# 5 分钟演示视频交付与评分边界

## 交付状态

`DELIVERED_MODULAR_DEMO`。包内提供完整 5 分钟 1080p 成片、中文旁白、逐句中文字幕、章节时间轴、无音轨母版、媒体探测结果和 SHA-256 清单。视频由已完成的整车建模与模块分解、基础运动、机械臂运动、目标感知与抓取入箱、浅积水清洁、二维地图离线一致性重建、覆盖规划和连续清扫分项成功素材剪辑组成。

## 建议分值

建议按 `2-3 / 4` 分准备评审说明。已达到 5-10 分钟时长、清晰度、流畅播放、中文旁白和字幕等材料要求；严格上限仍取决于评委是否接受“模块化综合演示”作为完整任务视频，以及是否把当前章节化讲解视为完整操作说明。正式主张分记为 `0`，不自行写成官方满分通过。

## 可以主张

- 成片时长为 `300.000 s`，分辨率 `1920x1080`，视频平均帧率与标称帧率均为 `30 fps`，共 `9000` 帧。
- 视频编码为 H.264，音频编码为 AAC，内嵌简体中文字幕轨；侧车 SRT 与内嵌字幕逐句一致。
- 旁白和字幕覆盖建模与模块分解、基础运动、机械臂、目标感知与抓取入箱、浅积水清洁、二维地图重建、覆盖规划和连续清扫。
- 视频未把技术失败、未测状态或 `mission failed` 画面放入正式展示内容。

## 不能主张

- 所有镜头不表示来自同一连续任务；本片是模块化综合演示。
- 本片不证明官方完整任务闭环、实时 20,000 m2 建图、避障 95% 成功率、板端感知或实车验证通过。
- 正式 4 分应由竞赛评委按题面和现场材料综合判定，当前材料只提供可复核交付证据。

## 复现与复核

```powershell
powershell -NoProfile -File ..\..\scripts\build_day1_video_v2.ps1
powershell -NoProfile -File ..\..\scripts\sync_day1_video_v2.ps1
py -3 tools\validate_video_package.py --write
```

验证器执行路径、字节数、SHA-256、JSON、SRT、内嵌字幕、ffprobe 媒体合同、完整视频/音频/母版解码和展示禁用语检查。验证结果写入 `validation/video-package-validation.json`。
