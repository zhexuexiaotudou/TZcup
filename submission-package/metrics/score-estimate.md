# 官方评分内部估算

本文件是根据 DG-202604 官方评分表和当前封存证据形成的内部评审估算，不是组委会评分。估算把“实测 PASS”“受控或离线 PARTIAL”“NOT_MEASURED”和“设计材料”分开处理，不使用未提供的虚拟用户、现场客户或长期可靠性数据。

## 估算区间

|情景|总分区间|解释|
|---|---:|---|
|保守|49-56|严格把 controlled、offline、design-only 证据只算低档材料分|
|合理|57-65|评委接受受控/离线证据作为部分实现，并认可模块化视频和文档| 
|乐观|66-69|评委认可全部局部成果、操作说明和产业化准备材料，但仍不把未测项写成 official PASS|

当前最可能的落点是三等奖上沿到二等奖下沿附近。正式结果仍由组委会按原口径判定。

## 风险

- 官方明确把关键技术指标未达到最低要求列为一票否决风险。准确的“最低要求”和识别统计口径尚未由官方补充说明。
- 若评委要求 20,000 m² 必须是 Gazebo live SLAM、避障必须给出完整成功率、识别必须给官方真实域指标，则这些项目前不能按 PASS 计分。
- 代码包是选交加分材料，不替代性能指标；视频操作说明也不把模块化成片升级为同一连续任务。
