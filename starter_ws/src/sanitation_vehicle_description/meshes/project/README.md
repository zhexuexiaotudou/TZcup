# Project-owned formal vehicle meshes

The `cleaning/` and `storage/` STL files are generated artifacts from
`cad/formal_vehicle/generate_cleaning_storage_meshes.py` and are distributed
under the package Apache-2.0 license. Run the generator after changing any
dimension; do not hand-edit binary STL output.

STL coordinates are metres. These are visual meshes only. Authoritative
collision, mass, inertia and joints remain in the high-fidelity Xacro modules.
The component exteriors and mounting interfaces are nominal reconstructions;
no claim is made about hidden manufacturer-internal motor or pump geometry.
